01 — Overview

프로젝트 개요

MBTI 직업 추천 · 6개 능력치 시스템 · 파티 보완 추천을 통합한 RPG 매칭 시스템

MBTI 성격 유형별 직업 추천, 6개 능력치 시스템, 파티 구성 시 부족한 능력을 다른 파티원으로 보완하는 시스템, 그리고 상황(퀘스트)에 따라 필요한 파티원을 추천하는 종합 RPG 매칭 시스템입니다.

캐글의 16 Personalities 데이터셋(약 6만 건)을 기반으로 XGBoost 분류 모델 4개를 학습해 사용자의 성격 지표(E/I, N/S, T/F, J/P)를 예측합니다.

예측된 MBTI 확률값은 6가지 RPG 스탯으로 수치화되고, SQLite3 DB에 저장된 길드원들 중 약점 스탯을 보완하는 최적 파티원 3인을 자동 추천합니다.

04 — Machine Learning

ML 파이프라인

16분류 문제를 4개의 이진 분류로 분해 — XGBoost 지표별 독립 학습

01
이진 분류 전략
EI·NS·TF·JP 각 지표별 독립 XGBoost 모델을 학습하여 복잡한 16분류를 단순화.
02
XGBoost 설정
트리 100개, 최대 깊이 4, 학습률 0.1. 훈련 80% / 테스트 20% 분할.
03
확률값 활용
predict_proba()로 연속 확률(0~100%) 추출. 50% 기준 유형 결정 후 스탯 계산에도 직접 활용.
04
모델 직렬화
학습된 4개 모델과 특성 인덱스를 models.pkl로 저장. Flask 서버 시작 시 로드.

06 — RPG Stat System

RPG 스탯 변환 알고리즘

공식: (두 지표 확률 평균) × 9 + 1 → 최솟값 1, 최댓값 10 · 직업 보너스 추가 적용

⚔️
무 력
(S + T) / 2 × 9 + 1
감각(S)으로 현실을 인지하고 사고(T)로 논리적 행동 → 물리적 공격력
✨
마 력
(N + I) / 2 × 9 + 1
직관(N)으로 추상 개념을 이해하고 내향(I)으로 내면 에너지 집중 → 마법 능력
✝️
신성력
(F + J) / 2 × 9 + 1
감정(F)으로 타인을 배려하고 판단(J)으로 도덕적 결정 → 신성한 힘
⚡
민첩성
(P + E) / 2 × 9 + 1
인식(P)으로 유연하게 대응하고 외향(E)으로 빠르게 행동 → 민첩한 움직임
👑
통솔력
(E + J) / 2 × 9 + 1
외향(E)으로 사람들과 소통하고 판단(J)으로 결정을 주도 → 리더십
🛡️
생존력
(S + I) / 2 × 9 + 1
감각(S)으로 위험을 감지하고 내향(I)으로 침착함 유지 → 생존 능력

08 — Key Features

핵심 기능

설문 · 예측 · 시각화 · 파티 추천을 하나의 플로우로 연결

🎲
랜덤 문항 출제
60문항에서 지표별 4문항씩 총 16문항을 매 세션마다 랜덤 추출. 반복 응시 시에도 신선한 경험 제공.
📊
레이더 차트 시각화
Chart.js로 6개 RPG 스탯을 레이더 차트로 표현. 내 스탯과 파티 합류 후 평균을 겹쳐 취약점과 보완 효과를 직관적으로 확인.
🤝
지능형 파티 추천
하위 3개 스탯을 식별해 각 스탯이 가장 높은 길드원을 DB에서 조회. WHERE NOT IN으로 중복 직업 제외.
⚔️
퀘스트별 파티 추천
던전·축제·알현·야영·유적·전투·연구·파티 8가지 상황별로 필요한 능력치에 맞춘 최적 파티 조합 제시.
🏷️
직업별 특성 보너스
16개 직업별 스탯 보너스 적용. 기본 스탯에 직업 특색을 더해 동일 MBTI라도 차별화된 수치 구성.
📱
QR 코드 즉시 접속
서버 시작 시 로컬 IP 기반 URL을 자동 생성하고 QR 코드 저장. 같은 네트워크 내 모바일에서 즉시 접속 가능.
